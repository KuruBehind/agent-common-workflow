# E2E QA — 에이전트가 직접 조작한다

QA 는 "이렇게 해 보세요" 가 아니라 **에이전트가 열고, 누르고, 찍고, 데이터까지 확인한 결과**를 보고하는 일이다. 사용자에게 맡기는 것은 **인증(로그인·OTP·결제 인증)** 뿐이다.

## 원칙

- **직접 조작** — Playwright 영구 프로필 브라우저를 CDP 로 붙어 클릭·입력·스크린샷. "○○ 버튼을 눌러 주세요" 금지.
- **인증만 요청** — 로그인 화면을 띄워 놓고 한 줄로 요청. 여러 서비스면 한 메시지에 묶는다. 비밀번호·OTP 는 묻지 않는다.
- **한 프로필·여러 탭** — 앱·BO·HQ 를 같은 프로필의 탭으로 열고 `QA_TAB` 으로 전환. 서비스마다 재기동(로그인 소실)·헤드리스 새 컨텍스트 금지.
- 기술 문제는 `communication` 스킬대로 10회 이상 스스로 시도. 로그인 만료·2단계 인증만 즉시 요청.

## 절차

1. **최신 코드로** — 배포본이 아니라 `origin/dev`+작업 브랜치를 로컬 빌드해 띄운다. 옛 서버는 **내가 띄운 PID 만** 종료. 브라우저·dart 등 전역 종료 금지.
2. **브라우저 기동** (한 번만, `run_in_background` — `&` 는 셸과 함께 정리될 수 있다) — `QA_NAME=<티켓> node $SKILLS/e2e-qa/scripts/qa-browser.mjs <URL…>`. URL 수만큼 탭이 열리고, 프로필은 `%TEMP%/claude/qa-browser-<QA_NAME>` 에 남아 다음 세션에도 로그인이 유지된다.
3. **인증 요청** — 로그인 화면 스크린샷을 본 뒤 요청.
4. **조작** — `QA_SHOT_DIR=<스크래치패드 절대경로> node $SKILLS/e2e-qa/scripts/qa-act.mjs <NN>_<단계> '<JSON 동작>'`. 동작 목록은 스크립트 머리말. 매 실행 뒤 스크린샷 경로가 찍힌다 — **반드시 Read 로 보고** 다음 동작을 정한다. 보지 않은 화면을 "정상" 이라 하지 않는다.
5. **종료** — `node $SKILLS/e2e-qa/scripts/qa-stop.mjs`. node 런처 kill 로는 Windows 에서 Chrome 이 살아남는다(실측). 끝난 티켓의 프로필은 지운다(로그인 토큰이 남는다).

`$SKILLS` = `~/.claude/skills`(Claude) 또는 `~/.agents/skills`(Codex). Node PATH·포트·빌드 명령·계정·DB 조회는 워크스페이스 `workflow-env` 「E2E QA」 절. 임시 스크립트는 루트가 아니라 스크래치패드에.

## 판정 규칙

- **화면 + 서버 증빙을 짝으로** — DB·API·함수 로그 중 그 기능의 정본을 읽는다. "주문됨" 은 주문 노드 생성·카트 비움·금액 일치가 모두 맞을 때다.
- **동작 직후 상태로 결론 내리지 않는다** — 로컬 상태가 잠시 비는 경우가 있다. 다른 화면을 거치거나 새로고침한 뒤 판정.
- **실패 경로도 한 건 이상** 실제로 밟는다(409·권한 없음·빈 상태). 서버 코드가 화면 문구로 바뀌는지 본다.
- 테스트 데이터는 dev 에만. DB 직접 쓰기는 **무엇을 바꾸는지 보고→승인 후**, 원복 값을 보고서에 남긴다. 운영 데이터는 읽기만.
- 캔버스 앱(Flutter 웹)은 DOM 이 없어 스크린샷에서 좌표를 읽어 클릭한다. 좌표 기준은 출력되는 `viewport=` 값(창 크기와 다르다)이고, QA 중 창 크기를 바꾸지 않는다. 오버레이(튜토리얼·툴팁)는 닫고 진행.
- 배치·스케줄러 대기가 끼면 끊고 "다음 확인 시각" 을 적어 백그라운드·다음 세션으로. 포그라운드 대기 금지.

## 보고

결론 먼저, 그다음 표 — 각 행 **동작 → 기대 → 실제(스크린샷 경로 전체) → 판정**. 실패 항목은 "무엇이 멈추나·라이브 영향" 을 실제 기준으로(과장 금지). 범위 밖 결함은 고치지 말고 후속으로 분리. 마지막에 남은 확인·되돌릴 테스트 데이터. 티켓이 있으면 Jira 코멘트(`jira-tickets`).

## 함정

| 증상 | 대응 |
|------|------|
| `connectOverCDP` 실패 / 재기동 시 프로필 잠김 | 이전 Chrome 이 살아 있음 → `qa-stop.mjs` 후 같은 `QA_NAME`·포트로 재기동 |
| `QA_TAB 에 맞는 탭 없음` 으로 멈춤 | 정규식이 URL 과 안 맞음. 출력된 탭 목록 보고 수정(다른 탭에서 조작하는 사고 방지용) |
| 동작 실패·`_FAIL.png` | 그 화면을 먼저 본다 — 오버레이·미로딩·좌표 어긋남·캔버스 앱에 `clickText` 사용 |
| 로그인했는데 게스트 취급 | 새로고침 후에도 그러면 재로그인 요청(인증이므로 즉시) |
| prod·dev 를 같은 포트에 번갈아 띄움 | 스토리지가 섞여 무한 로딩. 환경마다 포트 고정 |
